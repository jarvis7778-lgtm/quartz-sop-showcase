## 章节详细内容

### 第1章：从零开始认识单片机
**核心知识点：**
- 什么是单片机？与电脑、手机的本质区别
- 常见单片机家族对比：Arduino (AVR)、ESP32 (WiFi/BLE)、STM32 (ARM)
- Arduino UNO 板子结构详解（引脚、电源、USB接口、ATmega328P）
- 开发环境搭建：Arduino IDE 2.x 安装与配置
- 第一个程序：点亮LED（Blink）
- 开发工具对比：Arduino IDE vs PlatformIO

**实操项目：**
- 项目1.1：LED闪烁（Blink）——理解 setup() 和 loop()
- 项目1.2：按键控制LED——数字输入 digitalRead()
- 项目1.3：流水灯效果——for循环 + 数组

**本章要点：** 建立"代码控制硬件"的基本概念，不需要任何编程基础。

---

### 第2章：Arduino 编程基础
**核心知识点：**
- Arduino 程序结构深入：setup() 初始化、loop() 主循环
- 数字输入输出：digitalRead / digitalWrite
- 模拟输入输出：analogRead (ADC) / analogWrite (PWM)
- 常用C++语法：变量、条件判断(if/else)、循环(for/while)
- 串口监视器调试：Serial.begin() / Serial.println()
- 常见传感器基础：模拟传感器 vs 数字传感器
- I2C/SPI 通信简介（为后续章节铺垫）

**实操项目：**
- 项目2.1：光敏电阻控制LED亮度（模拟读取 + PWM输出）
- 项目2.2：电位器调节舵机角度（Servo库）
- 项目2.3：超声波测距并在串口显示距离（HC-SR04）
- 项目2.4：DHT11温湿度读取并串口显示

**调试技巧：**
- 串口监视器高级用法
- 常见编译错误排查
- 接线检查清单

---

### 第3章：ESP32 进阶开发
**核心知识点：**
- ESP32 vs Arduino UNO：能力对比（32位双核240MHz vs 8位16MHz）
- ESP32-S3 特色：AI向量指令(SIMD)、USB OTG、摄像头接口
- ESP32 开发板选型指南（DevKitC / S3-DevKitC-1 / C3-DevKitM-1）
- Arduino框架 vs ESP-IDF 框架的关系
- ESP32 的 WiFi 功能：连接、断线重连
- ESP32 的 BLE 蓝牙基础
- Web 服务器开发
- OTA 空中升级

**实操项目：**
- 项目3.1：ESP32连接WiFi并获取网络时间（NTP）
- 项目3.2：ESP32 Web服务器——浏览器远程控制LED
- 项目3.3：ESP32蓝牙串口透传（BLE UART）

---

### 第4章：串口通信（UART）
**核心知识点：**
- 串口通信原理：波特率、数据位、停止位、校验位
- UART 帧格式详解（标准：8N1）
- Arduino/ESP32 的 Serial 库详解（Serial, Serial1, Serial2）
- ESP32 的三个硬件UART（UART0/1/2）及引脚映射
- USB-TTL 模块使用（CH340/CP2102）
- 两块开发板之间的 UART 通信
- 串口调试技巧与常见问题排查

**实操项目：**
- 项目4.1：Arduino与电脑串口双向通信（Serial Monitor交互）
- 项目4.2：ESP32读取GPS模块（NEO-6M）NMEA数据
- 项目4.3：两块ESP32通过UART互传温湿度数据

**常见问题：**
- 接线错误（TX→RX 交叉连接）
- 波特率不匹配
- 串口被占用（上传程序 vs 串口监视器冲突）

---

### 第5章：RS485 工业通信
**核心知识点：**
- RS485 vs UART vs RS232：为什么工业场景用RS485？
- MAX485芯片工作原理（半双工、A/B差分信号、DE/RE方向控制）
- RS485接线规范：A对A、B对B，终端电阻
- Modbus RTU 协议基础（地址、功能码、CRC校验）
- 常用功能码：03读保持寄存器、06写单个寄存器
- ESP-IDF 的 UART RS485半双工模式
- RS485多设备通信（一主多从拓扑）

**实操项目：**
- 项目5.1：ESP32 + MAX485 基础通信测试（回环测试）
- 项目5.2：RS485多设备通信——一主两从
- 项目5.3：ESP32读取 Modbus 电能表数据（SDM120）

**前置知识说明：** 本章适合有工业控制/仪表通信需求的学习者。如果只做智能家居可跳过，直接学第6章MQTT。

---

### 第6章：MQTT 协议与物联网通信
**核心知识点：**
- MQTT协议原理：发布/订阅模型、Topic主题、QoS级别
- MQTT Broker 概念：Mosquitto / EMQX 5.x
- PubSubClient 库使用（经典方案）
- AsyncMqttClient 库介绍（异步方案）
- MQTT 5.0 新特性简介
- 消息格式设计：JSON 结构化数据
- 安全性：MQTT over TLS/SSL、用户名密码认证
- 公共 MQTT Broker 列表：broker.emqx.io、test.mosquitto.org

**实操项目：**
- 项目6.1：ESP32连接EMQX公共Broker并收发消息
- 项目6.2：ESP32 + DHT22 上传温湿度到MQTT Topic
- 项目6.3：通过MQTT远程控制继电器开关
- 项目6.4：MQTTX桌面客户端调试工具使用

---

### 第7章：Home Assistant 智能家居平台
**核心知识点：**
- Home Assistant 简介：开源智能家居中枢
- 安装方式：树莓派5 (推荐) / PC Docker / 虚拟机
- HA 基本概念：Entity实体、Integration集成、Automation自动化
- ESPHome 固件生成器：YAML配置，不用写C代码
- ESPHome 常用组件：sensor、switch、binary_sensor
- HA + MQTT 集成配置
- HA 自动化规则编写（触发条件 → 执行动作）
- 设备发现与集成

**实操项目：**
- 项目7.1：树莓派5安装 Home Assistant OS
- 项目7.2：ESPHome 制作温湿度传感器节点并接入HA
- 项目7.3：HA 自动化——温度超过阈值自动打开风扇（继电器）
- 项目7.4：ESP32通过MQTT接入HA（不用ESPHome的替代方案）

### 第8章：传感器与执行器综合实战
**核心知识点：**
- 常用传感器分类：温度/湿度/光照/气体/距离/运动
- 传感器数据滤波：移动平均、中值滤波
- 继电器安全使用：强电隔离、光耦保护
- 舵机控制原理（PWM 50Hz，0.5ms-2.5ms脉宽）
- 步进电机控制（28BYJ-48 + ULN2003驱动板）
- 多传感器数据融合思路

**实操项目：**
- 项目8.1：智能环境监测站
  - 硬件：ESP32 + DHT22 + 光敏电阻 + PIR
  - 功能：采集温湿度/光照/人体感应 → MQTT → HA面板显示
- 项目8.2：自动窗帘系统
  - 硬件：ESP32 + 光敏电阻 + 28BYJ-48步进电机
  - 功能：光照过强自动关窗帘，光照不足自动开窗帘
- 项目8.3：智能安防系统
  - 硬件：ESP32 + PIR + 蜂鸣器 + 继电器(控制灯)
  - 功能：人体感应 → 蜂鸣器报警 + 灯光闪烁 + MQTT推送通知

**每个项目要求：** 完整BOM表 + 接线图 + 代码 + 调试指南

### 第9章：TinyML 边缘AI
**核心知识点：**
- 什么是TinyML？为什么在MCU上跑AI？
- TinyML vs 云端AI：延迟、隐私、离线能力
- TensorFlow Lite Micro 架构和工作流程
- 完整流程：数据采集 → 模型训练 → 量化 → 部署
- Edge Impulse：无代码/低代码TinyML开发平台
- ESP32-S3 的AI加速能力（ESP-NN SIMD向量指令）
- ESP-DL 框架简介
- 模型优化技术：INT8量化、剪枝、知识蒸馏
- 内存和计算资源评估

**实操项目：**
- 项目9.1：ESP32-S3 手势识别（MPU6050 IMU + TFLite Micro）
  - 训练数据采集 → Edge Impulse训练 → 部署到ESP32-S3
- 项目9.2：ESP32-S3 图像分类（OV2640摄像头 + TFLite Micro）
  - 识别猫/狗/人等常见物体
- 项目9.3：ESP32-S3 语音关键词识别（Micro Speech）
  - "开灯"/"关灯" 离线语音识别
- 项目9.4 *(可选)*：Jetson Nano / Jetson Orin Nano 目标检测
  - YOLOv8 + TensorRT 加速推理

**替代方案说明：** Jetson Nano价格波动大且已停产多次。如预算有限，可用树莓派5 + Coral USB加速器替代，或专注ESP32-S3的TinyML能力。
