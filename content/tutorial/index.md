## 🛠️ 开发环境

### 必需软件

| 软件 | 用途 | 下载链接 |
|------|------|---------|
| Arduino IDE 2.x | 主要开发环境 | https://www.arduino.cc/en/software |
| ESP32开发板支持包 | ESP32编程 | Arduino IDE → 开发板管理器搜索"esp32" |
| MQTTX | MQTT调试工具 | https://mqttx.app |
| Edge Impulse | TinyML模型训练 | https://www.edgeimpulse.com |

### 可选软件

| 软件 | 用途 |
|------|------|
| PlatformIO | 更强大的嵌入式开发IDE |
| Home Assistant | 智能家居平台 |
| Ollama | 本地LLM推理 |

## 💡 使用建议

1. **按顺序学习**：第1-6章是基础，建议按顺序学完
2. **多动手**：每章的项目都要实际做一遍
3. **遇到问题**：查看[附录A](#常见问题)或搜索解决方案
4. **预算有限**：从入门套件开始，后续按需添加
