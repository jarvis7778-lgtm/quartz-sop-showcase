# New Member Onboarding

Use this page as a starter SOP for welcoming new contributors.

## Before the first day

- Create the required accounts.
- Share the team handbook link.
- Assign an onboarding buddy.
- Prepare starter tasks with clear owners.

## First-week checklist

| Task                          | Owner      | Done |
| ----------------------------- | ---------- | ---- |
| Read core SOPs                | New member | ☐    |
| Confirm access to tools       | Buddy      | ☐    |
| Complete a small contribution | New member | ☐    |
| Review feedback process       | Lead       | ☐    |

## Notes

Replace this page with your own onboarding policy. Avoid publishing private names, internal URLs, credentials, or unreleased project details.
